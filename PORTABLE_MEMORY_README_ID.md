# Cara memakai memory portabel

- `memory_profile.md`: fakta/preferensi stabil dan konteks proyek. Baca dan edit sebelum dibagikan.
- `memory_journal.jsonl`: kosong di paket awal. Pada aplikasi hasil build ini, auto-save aktif secara default atas permintaan pengguna dan menyimpan prompt/jawaban AI secara lokal; preferensi dapat dimatikan. Beberapa credential umum disamarkan, tetapi periksa jurnal sebelum membagikannya.
- `MEMORY_TRANSFER_PROMPT_ID.md`: prompt untuk menjelaskan cara kerja kepada AI lain.
- `MEMORY_SCHEMA.json`: definisi file.
- `FEATURE_CATALOG_ID.md` / `.csv`: 220 konsep fitur dan status implementasi/perencanaan.

ZIP memori versi terbaru juga menyertakan `TOKEN_OPTIMIZATION_PLAYBOOK_ID.md` untuk menjelaskan 60 teknik efisiensi yang aktif/pengaman/eksperimen. Data keuangan SQLite sengaja tidak ikut diekspor; ekspor sendiri transaksi yang dibutuhkan melalui CSV.

Profil portabel bukan backup sempurna dari seluruh percakapan ChatGPT, dan tidak menyalin model, bobot, atau pikiran internal suatu AI. Ia membawa konteks tertulis agar asisten lain bisa melanjutkan pekerjaan dengan konsisten.
